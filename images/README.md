# Evidence policy

The repository uses Mermaid architecture diagrams and written validation matrices instead of the original coursework screenshots. That choice keeps school branding, lab identities, hostnames, addresses, and window metadata private while still showing the design and verification approach.

Future screenshots are optional rather than required for the case studies. Any image added here must be independently captured, use fictional identities, and be reviewed for:

- names and usernames;
- domains, IP addresses, and hostnames;
- school or lab-provider branding;
- credentials, product keys, tokens, and recovery information; and
- browser profiles, timestamps, notifications, and unrelated window content.
